
# AI CCTV Surveillance System

## 📌 Project Overview

The AI CCTV Surveillance System is an intelligent security monitoring application that uses Artificial Intelligence, Computer Vision, and Machine Learning to monitor CCTV video feeds. It helps detect suspicious activities and unusual events automatically, reducing the need for continuous manual monitoring.

## 🎯 Objectives

- Automate CCTV surveillance using Artificial Intelligence.
- Monitor live video feeds.
- Detect suspicious activities and unusual events.
- Improve security through automated monitoring.
- Reduce manual surveillance efforts.

## 🚀 Features

- AI-based video surveillance.
- Real-time video monitoring.
- Suspicious activity detection.
- Automated event detection.
- Security alerts and notifications.
- Video processing using computer vision.

## 🛠️ Technologies Used

- Python
- OpenCV
- Artificial Intelligence
- Machine Learning
- Computer Vision
- NumPy

## 💡 Applications

- Home Security

- College and School Security
- Public Area Monitoring
- Industrial Security
